# Contributing

Thanks for your interest in GetMyData Agent.

- Open a pull request against `main`. Keep changes small and focused.
- Before you push, run the content check locally:

  ```
  bash scripts/prepublish-check.sh
  ```

  CI runs the same check on every push and pull request; it must pass before merge.
- Do not commit credentials, personal data, internal URLs or non-public business details.
- By contributing, you agree that your contribution is licensed under the Apache License 2.0.

For questions, contact support@getmydata.io.
